Expense Tracker

Java 17 · REST API · zero dependencies · 2026

A REST API for tracking spending, written in plain Java with no external libraries at all. I used the JDK's built-in HTTP server and wrote my own small JSON parser. Expenses save to a CSV file with atomic writes, so a crash halfway through a save can't corrupt your data.

It also has a web page built entirely in Java with no JavaScript, just HTML forms. It uses the Post/Redirect/Get pattern so refreshing doesn't add the same expense twice, and it escapes user input so nobody can inject code. It has filters by category and date, monthly summaries, and a test suite.

Each layer only talks to the one below it, so features like automatic categorization and spending analytics can be added without reworking existing code.
